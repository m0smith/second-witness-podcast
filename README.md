# Second Witness Podcast

Public RSS feeds generated by the private Second Witness project, following the weekly
*Come, Follow Me* (Old Testament 2026) study.

| Feed | Contents |
|------|----------|
| `podcast.xml` | The weekly lesson, assigned scriptures, and referenced Church resources that expose audio |
| `liahona.xml` | Referenced Liahona / general conference audio only |
| `web.xml` | The assigned readings in the public-domain World English Bible (eBible.org audio) |

The feeds point to official Church-hosted audio (and eBible.org for the WEB feed); this repository does
not redistribute any audio files.

## Update cadence

A GitHub Actions workflow regenerates the feeds **weekly** (Mondays 07:15 UTC) and publishes the whole
week's content at once. It can also be run manually (`workflow_dispatch`).

## Development

Requires Node.js 22+. No dependencies.

```bash
node --check scripts/generate-podcast.js        # syntax check
node --test "test/*.test.js"                    # offline unit tests
node scripts/generate-podcast.js --date 2026-10-12   # regenerate a week (needs network)
```

Generating rewrites `podcast.xml`, `liahona.xml` and `web.xml`; discard those changes before committing
(`git checkout -- podcast.xml liahona.xml web.xml`). Only the scheduled workflow commits feeds.
