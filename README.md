# Second Witness Podcast

Public RSS feeds generated by the private Second Witness project.

- `podcast.xml` — Come, Follow Me scriptures plus referenced Church resources that expose audio.
- `liahona.xml` — referenced Liahona/general conference audio only.

The feeds point to official Church-hosted audio; this repository does not redistribute the audio files.

Updated daily so each week's listening can be released progressively across the week.
